# Traffic_Crashes_Raw_Dataset

This dataset is too large to store directly in this GitHub repository. It is publicly available from the City of Chicago Data Portal:

Source:
City of Chicago Data Portal  
Traffic Crashes – Crashes  
https://data.cityofchicago.org/Transportation/Traffic-Crashes-Crashes/85ca-t3if

Download Instructions:

1. Visit the link above
2. Click "Export"
3. Choose CSV format
4. Save the file as:
data/raw-data/Traffic_Crashes_-_Crashes.csv

The project assumes the file is stored in this location for full reproducibility.
